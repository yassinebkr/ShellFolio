# Credits and artwork

- **AienTech:** terminal-inspired GitHub portfolio experiments, particularly [AienTech/aientech](https://github.com/AienTech/aientech), influenced the project's visual direction. ShellFolio's virtual command engine and browser UI are independent implementations.
- **Debian swirl:** graphic based on the [Simple Icons Debian vector](https://github.com/simple-icons/simple-icons/blob/develop/icons/debian.svg), which traces its identity to the Debian Project. Refer to the [official Debian logo guidelines](https://www.debian.org/logos/) for usage and licensing details. The Debian mark is used to identify the simulated environment, with no Debian Project affiliation implied.
- **XFCE Terminal:** visual conventions of the desktop terminal are used as a reference for the browser's window chrome and shell presentation.
